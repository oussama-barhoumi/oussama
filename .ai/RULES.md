# Rules

## Design

- Always follow the design system defined in `DESIGN.md`.
- Do not introduce colors outside the approved palette (`#C2AE93`, `#762C19`, `#C55347`, `#7A4456`) without explicit approval.
- Do not introduce additional fonts without a clear design reason.
- Do not add decoration before solving typography, layout, and hierarchy.

## Motion

- Every animation must serve a purpose — no decorative-only animations.
- Prefer scroll-based transitions, smooth reveals, and meaningful hover states.
- Never use motion that hurts usability or degrades performance.

## Responsive

- Every UI must be tested and work across desktop, laptop, tablet, and mobile.
- Mobile is never an afterthought — design mobile-first when in doubt.

## UI Priority Order

When making design decisions, resolve in this order:
1. Typography
2. Layout
3. Spacing
4. Visual hierarchy
5. Interaction
6. Motion
7. Decorative details
