# Design System

## Visual Direction

The portfolio uses a **premium, cinematic, editorial** visual language.

The design should feel:

- Warm
- Sophisticated
- Artistic
- Cinematic
- Modern
- Minimal
- Premium

Avoid generic SaaS aesthetics unless explicitly requested.

---

## Color System

The primary palette is based on the following distribution:

| Role | Hex | Usage | Weight |
|------|-----|-------|--------|
| Warm Beige | `#C2AE93` | Primary background and large visual surfaces | 60% |
| Deep Burgundy Brown | `#762C19` | Dark sections, strong typography, major visual blocks | 25% |
| Terracotta | `#C55347` | Primary accent, CTA, interactive states, important highlights | 10% |
| Muted Plum | `#7A4456` | Secondary accents, details, subtle visual elements | 5% |

### Color Rules

- Do **not** randomly introduce new colors.
- If another color is required for accessibility, error states, success states, or technical UI requirements, use it **only when necessary** and keep it visually consistent with the existing palette.
- Do **not** replace the primary palette without explicit approval.

---

## Typography

Typography should prioritize:

- Strong hierarchy
- Large editorial headings
- Clean readable body text
- Intentional spacing
- Premium visual rhythm

Do not introduce additional fonts without a clear design reason.

---

## Motion

Animations should **communicate something**.

**Prefer:**
- Smooth reveals
- Scroll-based transitions
- Subtle parallax
- Text reveals
- Image transitions
- Meaningful hover interactions
- Cinematic page transitions

**Avoid:**
- Excessive bouncing
- Random animations
- Animation everywhere
- Motion that hurts usability
- Heavy effects that reduce performance

Motion should enhance the experience, not distract from the content.

---

## Responsive Design

The design must work properly across:

- Desktop
- Laptop
- Tablet
- Mobile

Never sacrifice usability for visual effects. Mobile is not an afterthought.

---

## UI Principles

Prioritize in this order:

1. Typography
2. Layout
3. Spacing
4. Visual hierarchy
5. Interaction
6. Motion
7. Decorative details

Do not add decoration before solving hierarchy and usability.
Typography

Font System

The portfolio uses a three-font typography system designed for a premium, futuristic, editorial aesthetic.

Primary Display — Tanker

Tanker is the primary display font.

Use it for:

* Hero headlines
* Large section titles
* Key statements
* High-impact typography
* Short visual labels

Style: Bold, futuristic, expressive, high visual impact.

Tanker should be used selectively. Avoid using it for long paragraphs or dense UI.

⸻

Secondary Display — Kola

Kola is the secondary display/accent font.

Use it for:

* Secondary headings
* Editorial accents
* Featured words
* Creative section labels
* Special visual moments

Style: Distinctive, artistic, experimental.

Kola should complement Tanker rather than compete with it.

⸻

UI & Body — Plus Jakarta Sans

Plus Jakarta Sans is the functional font for the entire interface.

Use it for:

* Body text
* Navigation
* Buttons
* Forms
* Cards
* Metadata
* Captions
* UI components

Recommended weights:

* 400 — Regular / body
* 500 — Navigation / labels
* 600 — Buttons / emphasis
* 700 — Strong UI emphasis

⸻

Typography Hierarchy

Hero / H1       → Tanker
Section H2      → Tanker
Creative Accent → Kola
Body            → Plus Jakarta Sans
Navigation      → Plus Jakarta Sans 500
Buttons         → Plus Jakarta Sans 600
Labels          → Plus Jakarta Sans 500
Metadata        → Plus Jakarta Sans 400–500

Design Principle

Tanker = Impact
Kola = Character
Plus Jakarta Sans = Clarity

The combination should feel premium, cinematic, modern, minimal, and slightly experimental without sacrificing readability.

Avoid using all three fonts heavily within the same component. Typography should remain intentional and hierarchical.
